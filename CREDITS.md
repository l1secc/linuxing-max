# Credits

Linuxing Max is original work. It does not bundle third-party artwork.

- **Wallpapers** — procedurally generated for this theme with ImageMagick
  (`tools/generate-wallpapers.sh`). No external images are used.
- **Font reference** — the wallpapers and waybar styles reference
  [JetBrainsMono Nerd Font](https://www.nerdfonts.com/) (JetBrains Mono +
  Nerd Font), licensed under the SIL Open Font License 1.1.
- **Icon theme** — `icons.theme` names `Yaru-prussiangreen`, the default
  Yaru icon theme shipped with Ubuntu-derived systems (GPL-3.0); it is not
  bundled, only referenced.
- **Architecture** — the scheme-bundle generator, switcher and bootstrap
  follow the conventions of Omarchy's own theming system and its community
  themes.
